# Design: Field Incident Log

## Mode

Operate. Users arrive to record and publish one problem with little ceremony.

## Visual world

Compact field-incident sheet: cool white work surface, deep ink structure, and
signal orange reserved for inherited parent context and decisive states. Labels
behave like terse form annotations; generous writing fields carry the hierarchy.

## Composition

- Full-width work sheet uses available napplet space, never a dashboard.
- Header states task and current root/child mode.
- Title and description dominate first viewport.
- Advanced protocol choices stay in one disclosure section.
- Bottom action rail pairs current readiness with one publish action.

## Interaction

- Intent-delivered child context appears as a clipped orange docket above form.
- Validation stays beside affected input and in one live status region.
- GSAP supplies short entrance, disclosure, context, and result transitions.
- Reduced-motion mode removes transforms and duration.

## Tokens

- Background: `#e9edf0`
- Surface: `#f8faf9`
- Ink: `#102832`
- Muted: `#5c6b70`
- Rule: `#bdc8c9`
- Signal: `#f15a29`
- Success: `#176b52`
- Error: `#a52a2a`
- Type: system UI with compact uppercase annotations and readable body text.

## Responsive behavior

Single column at every size. Inline field groups stack below 620px. Sticky action
rail becomes ordinary flow where viewport height or width makes it obstructive.
