# NOSTROCKET State

Shows NOSTROCKET by default and lets the user select other discovered kind `31108` rockets. Each state is centered on merit ownership. Each `merit` tag encodes `owner:approved-request-id:leadtime:last-leadtime-update:merits`. Display groups lots by owner and sums integer merit without floating-point loss.

User can refresh state, compare ownership in a pie chart, identify holders by public profile name and avatar, expand each holder to inspect approved merit-request lots, and see kind `1409` requests not yet represented by a state merit lot. Missing profiles degrade to pubkey labels and generated avatars. Provenance exposes event, publish time, ruleset, Bitcoin height, and selected NIP-66 relay set.
