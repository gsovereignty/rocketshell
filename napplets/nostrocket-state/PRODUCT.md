# NOSTROCKET State

Shows current NOSTROCKET Microsubjective Blockchain state, centered on merit ownership. Each `merit` tag encodes `owner:approved-request-id:leadtime:last-leadtime-update:merits`. Display groups lots by owner and sums integer merit without floating-point loss.

User can refresh state and expand each holder to inspect approved merit-request lots. Provenance exposes event, publish time, ruleset, Bitcoin height, and selected NIP-66 relay set.
